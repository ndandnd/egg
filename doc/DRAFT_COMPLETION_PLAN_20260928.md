# Finishing the expanded computational first draft

The v0.5 manuscript is complete but historical. Recent work has produced
reviewed computational evidence, not yet a consolidated revised paper. The first
computational draft does not depend on successfully training a learned method.

1. Finish the current intake package: one independent public timetable,
   prospectively grouped evaluation reservations, and a small synthetic size
   design under the current complete-replenishment model. Report input or witness
   limitations directly; do not change assumptions to manufacture successful cases.
2. Run one bounded, prospectively specified computational comparison using the
   admitted development inputs. Include cold solving, retained columns and a
   simple nearest-neighbor proposal baseline where its inputs are eligible.
   For price-only changes, include exact lowest-current-bill selection over the
   same stored fleet pool alongside nearest-neighbor lookup. Separate direct
   proposal, feasible repair and global verification. Include
   every attempted case and spent time; unresolved intervals remain results.
   Do not require favorable speedups or public optimality before writing.
3. Consolidate a reviewable LaTeX draft immediately after that comparison:
   exact mechanism/replication results; a concise physical and economic model;
   substantial computed examples with tables, intervals and figures; a clear
   price-taking-support versus strategic-price-impact discussion; and an honest
   account of what computation establishes and leaves open. Move development
   logs to supplementary material. Integrate the literature gaps from the user's
   review, shorten the abstract, and verify the rendered manuscript.

Nearest-neighbor retrieval is the minimal proposal baseline. A learned model is
an optional subsequent extension once data and evaluation justify it, not a
moving requirement that indefinitely delays the first readable draft. The first
draft is a research review milestone; it is not authorization to submit a journal
paper. Major scientific limits are stated in the manuscript, not hidden by adding
unbounded experiments. Revisit the plan if a genuine modeling or validity issue
makes its comparison uninterpretable, and report that issue to the user.
