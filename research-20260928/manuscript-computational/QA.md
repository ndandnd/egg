# Rendering and presentation check

Root compiled the final chapter with Tectonic and inspected all six rendered
pages after the final text/layout change. The final log has no overfull or
underfull boxes, missing characters, undefined references or TeX warnings.
Four tables and both vector figures are legible, no text/labels are clipped,
and the final evidence map and reproduction note are present. Widow/orphan
control and float boundaries keep each results subsection coherent.

Figure 1 includes all eight declared public target rows from the ordered
solver-baseline comparison only. Three failed targets have no interval and
retain their hatched paid-cost bars. Figure 2 includes all four public
fixed-price pairs, with positive values consistently denoting improvement and
numerical ties shown as ties. Both public depots remain one timetable.

The root regenerated figures solely from already reviewed public scalar CSVs.
The bundled document Python lacked Matplotlib, so the existing research
plotting environment was used; no optimizer ran. Tectonic fetched missing
standard TeX packages for the first build; subsequent final builds used its
cache. No full solver test suite was rerun for a manuscript-only change.

Final file hashes and byte sizes are recorded in ARTIFACTS.json. This check is
presentation QA and does not substitute for the separate factual review.
