# Composite training-shard interface, version 2

`python -m experiments.physical_learning_composite` creates one immutable train-only dataset after the shard-0 continuation has a successful wrapper and all 23 new cell receipts. It refuses the current partial parent alone. Input provenance includes the parent PREEMPTED Slurm accounting, complete archived file inventory, original 40-cell catalog/receipts, the single launch without receipt, continuation manifest/freeze/23-cell catalog/receipts, and its successful wrapper. Each row names its actual attempt and job; parent evidence is never relabeled as new-job evidence. Adapter, CLI, tests, interface policy, inputs, and outputs have SHA-256 hashes in `dataset_receipt.json`. The original 18 solver source pins remain unchanged.

The five JSONL tables are `cases`, `source_inputs`, `source_outcomes`, `target_inputs`, and `target_outcomes`. Cases contain exactly eight independent TRAIN base groups. There are 16 source outcomes and 48 target outcomes, but exactly one target outcome has `status=preempted_unreceipted_censored`, `evidence_class=preempted_unreceipted`, `paid_seconds=null`, `objective_exact=null`, `plan=null`, and no child receipt. The parent Slurm 713-second elapsed time and its 40 receipted child seconds are in `health.json` separately from continuation wrapper/child time; they are not allocated to the interrupted cell. A future accounting update requires a new version, not mutation of this output.

`source_inputs` holds pre-target full fleet plans, movement topology, and independent source replay. `target_inputs` holds the known case-specific source plan, target tariff, and exact direct rescore before target charging. `source_outcomes` and `target_outcomes` hold native status, failure/time, saved complete plans, exact observed curved costs, and source-market bounds. Identity fields (`base_id`, names, hashes, group, split, case identity) are join keys only. No numeric feature matrix is produced here; a later fit must declare a numeric feature allowlist and fit preprocessing only within training groups. Source-market bounds, charging outcomes, failure status, and winners cannot enter pre-target features.

The adapter independently regenerates every receipted catalog row from its saved evidence and checks full physical replay, source topology, case/market identities, hash lineage, and receipts. It never makes a child receipt for the interrupted cell. `health.json` reports eligible complete pairs and typed exclusions; a censored pair cannot become a zero-margin tie. The linear-tariff fixed-route LP's returned plan is scored with the exact curved tariff. That is a procedure-specific feasible cost, not a global curved optimum or an optimal route choice. Native source `certified` means source solver completion, not a curved-cost certificate. The train-only adapter never opens development or reserved test groups and does not fit a model.
