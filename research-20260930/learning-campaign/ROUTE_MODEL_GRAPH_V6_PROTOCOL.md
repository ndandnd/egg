Each source graph contains one vertex per trip plus separate depot source/sink vertices. A declared movement is a directed edge from its before-trip (or source) to its after-trip (or sink). Only existing edge inputs are standardized using the same unweighted fit-edge mean/scale as v3 (intercept fixed to mean0/scale1); inner and outer never fit a transform. Each node input concatenates incoming and outgoing means of those standardized17 features plus two binary source/sink role flags (36values). Empty neighborhoods produce zeros. These node aggregates are deterministic pre-solve representations; there is no extra node transform fitted on all groups. Table hashes, graph construction source hash, movement ordering, frozen feature names, fit transform and partition IDs identify all inputs.

Two fixed models share initialization order, float64 CPU arithmetic,32-wide edge/node embeddings, two directed message layers, and a32-wide edge decoder. In each layer, a tanh linear map of sender-state, receiver-state and edge embedding creates a32-vector message. Incoming and outgoing messages are pooled separately; a ReLU linear map of prior node state and both pools creates the next state. The decoder consumes final sender/receiver states, edge embedding and the original standardized17 edge features, then emits one binary logit. There is no dropout, normalization across graphs, sampling or class balancing.

Hard parameter ceiling18000 per model. Attention is single-head edge-conditioned attention; it is a task-specific graph network, not an exact implementation of published GraphSAGE or GAT. Attention vectors start at zero so initial pooling equals the mean arm; the remaining initialized tensors match under the same seed. The method draws inspiration from feature/neighborhood aggregation in [Hamilton, Ying and Leskovec, GraphSAGE](https://arxiv.org/abs/1706.02216) and masked neighbor attention in [Veličković et al., Graph Attention Networks](https://arxiv.org/abs/1710.10903). Those papers do not establish route performance for this imitation task.
