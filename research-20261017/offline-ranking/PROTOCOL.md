# Offline ranking protocol — frozen before first run

No solver calls, training, model selection, cluster work, or sealed-data access. Initial run cap 600 wall seconds, one CPU thread. Whitelist only public:hildenbrand15 and public:eberbach, from the two saved local-validate e3.json outputs. These are reused exploratory public cases, never a test claim. Read existing public score files only; do not open pooled labels. Replay saved reference plans with the independent native replay; choose minimum bill among admitted feasible saved plans per case, also retain all reference provenance. Reference means best observed *available* feasible plan, not optimum or historical best.

Compare saved v8 scores, deterministic nonlearned slack/deadhead/depot-access rank, and 20 seeded random rankings. CatBoost v5 is absent from local asset inventory: report unavailable, never substitute. Heuristic frozen formula: negative total moving-leg minutes minus 0.1 intertrip slack minutes plus 0.1 depot dwell minutes; moving legs have different endpoints, depot dwell is gap between inbound/outbound legs. No fitted coefficients.

Compute per-trip incoming and outgoing reference-edge recall at top m=1..8 over direct/depot candidates; boundary pullouts/pullins always survive. Also compute retention of all flexible reference edges and complete plans under union of incoming/outgoing top-m. Fixed global keep 5/15/30% is reported both pure and with production per-side top-3 floor; always keep boundaries. Explicit denominators and kept fraction. Ties use movement index. Group at network: Hildenbrand and Eberbach, equal network weight, no uncertainty claims from two reused networks. Log runtime, input/code SHA256 hashes, every failure, missing historical plans/scale references/CatBoost, and score identity checks. Persist failure records even if run fails. No changes to native solver or existing drivers.
