## Safe reuse boundary

The schema/binding functions, `q.start_evidence` and replay/billing arithmetic operate without dispatch; byte verifiers add read-only filesystem access. `WorkerClock` is only a local stateful guard. Existing modules have broad imports (`comparison_native_worker` imports planner/provider modules); `_analyze` also reads a fixture, charges CPU and writes a report. It is a useful list of checks, not a drop-in side-effect-free normalizer. `instrument_native60` monkeypatches native planner globals, and [`preflight.bound60`](../src/experiments/comparison_native_preflight.py#L310) monkeypatches qualification globals under a serialization lock. Neither belongs on an independent evidence-verification path. The inherited 30-second `q.completion_endpoint` is not the comparison endpoint; use the explicit 60-second validator as the reference.

## Minimal next implementation slice and hard blockers

Add one fail-closed byte-snapshot/replay verifier ahead of `NormalizedEvidence`: accept an independently trusted manifest/lock digest and expected cell, plus explicit artifact bytes. Reuse strict physical replay/bill functions and small read-only byte checks without importing the preflight/native worker or entering monkeypatch contexts. `lift_plan` first replays the submitted source plan, so it does not silently repair an invalid plan before full replay. Return verified assignment/byte/replay/bill facts and explicit missing-proof diagnostics; never copy worker `passed`, `integrity`, `replay_ok` or `path_qualification` flags. Do not normalize terminal timing until independent controller proof exists. Capture-envelope and native-log checks can follow using the exact source logic above, with explicit inputs rather than whole-run analysis.

Use narrow adversarial solver-free tests for a foreign task/lock, changed or omitted bytes, invalid physical events, a conflicting stored bill, and worker-only health claims. Subsequent terminal checks should cover malformed ACK and reversed/absent times. This needs no new controller framework or native run. Full deployment attestations remain blocked by (1) the absent prospective comparison trust-root binding, (2) absent independent completion/outcome/ACK/cleanup event observations sufficient for all terminal fields, and (3) any claim that runtime path hashes prove loaded bytes. If admission/extraction correctness is required, raw-capture-to-plan replay also remains an explicit gap.

The existing preflight report's declared scope is [two engineering80 paths only](../src/experiments/comparison_native_preflight.py#L471). Engineering path qualification and deployment are distinct: [`classify_endpoint`](../src/egglab/comparison_endpoint.py#L553) deliberately does not make qualification failure alone a deployment failure. No qualification `passed` flag authorizes dispatch, fills the comparison roster, establishes comparative quality, or replaces independently verified deployment evidence.
