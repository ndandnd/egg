## Evidence required before stronger claims

A useful learned advantage must survive BOTH frozen conventional controls under
matched acquisition/replanning conditions. Repeatable better system cost after
vehicle-count decomposition is more informative than another classification
metric. Price-information value additionally requires a comparably selected
trained tariff-blind model, fixed-pool/fixed-route charging reoptimization, and
prospective tariff/curvature/resource interventions. Input permutation alone
cannot establish information value, and the current graph model has no b input.

If a classical arm ties or dominates learning, report that and change the
scientific claim. Do not respond by adding model families or tuning on the
independent cohort. Resource-constrained route generation, LP-informed ranking
and learned ranking-loss improvements require an identified failure mechanism,
not the old sparse matching result. Recovery and unrestricted certification are
later separate measured stages. Generic pruning/recovery remain prior art.

This note is a handoff for the next frozen package, not a claim that all design
choices, a broad ML study or a new native launch are already complete.
