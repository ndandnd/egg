# Static worker interface

`worker.py` is new prospective source only. No imports, execution, compilation, hashes, data reads or tests were performed while writing it. It does not authorize dispatch.

CLI: `python worker.py --worker ABS_TASK_FOLDER --parent-anchor FLOAT --spec-sha256 HEX`. The task folder has the parent's placeholder receipt and immutable `spec.json`. Required spec keys: `root, task_id, group, base_id, services, route_source, target_source, case, prior_plan, expected_case_identity, expected_market_identity, a, b`. Optional exact-string keys are `baseline_F_exact` (this route/target's original fixed-witness cost) and `original_Ebar_exact`; the former is checked against independent fallback replay, while nonpositive/missing denominators yield an undefined normalized gain. `task_id` is copied unchanged. Cases are reconstructed from stored dictionaries, with no generation; one spec-byte SHA256 is checked after the parent anchor. Source admission/hashing is the parent's once-only responsibility; the worker checks loaded file paths and does not rehash source/row assets.

The worker uses unchanged `warm_replication/qp_control.py`, seed17, one call, native cutoff anchor+52 and final admission anchor+60, one thread/worker,90CPU-second limit and5GiB peak-RSS checks. All imports/build/copy/extraction/replay/publication cost is paid. No old campaign runner/scorer is imported. Original prior and selected result are replayed; selected canonical trip/movement path collections must agree with the prior. Fatal input/copy/path/resource failures latch `config_failure` and `fatal_contract`. Ordinary native/extraction failure can retain a valid preexisting fallback, with `cell_qualified=false`.

Durable files are `best-plan.json`, `brief-replay.json`, and atomic replacement of the parent's `receipt.json` placeholder. Only the full selected physical witness is written as a plan. Brief replay contains costs/energy/fleet/deadhead and an operations-summation residual, no load/session/SOC vectors. Extraction callbacks count event names only, not raw ledgers/matrices. Parent must observe process exit and the complete receipt by the same60s deadline; a child's prepublication timestamp alone is insufficient.

Receipt has `receipt_complete, method_endpoint_accepted, cell_qualified, config_failure, fatal_contract, resource_violation, identity_failure`, task/group/base/services/source identities, stop/failure/resources, copy/native status and settings. `candidate_bill_exact` (C), `fallback_bill_exact` (B), `retained_bill_exact`/`true_bill_exact` (U), `native_point` (N), `native_bound`/`native_lower_bound` and quality fields in `stats` are separate. Missing native calls stay null if the helper raises without returning. `numerical_agreement` records the source-point envelope; it is not an optimization-gap bound. `route_ordering` remains `UNRESOLVED`, `optimization_bound_supported=false`, `global_lower_bound=null`, `certificate_claim=false` even when nativeOPTIMAL/physical admission succeeds. Unsupported attribute values stay null.

**Candidate visibility and approved conditional path proof:** helper returns only the selected plan. If an admitted fresh candidate is not strictly better than fallback, its plan is not independently exposed. Before solving, the worker independently checks `pf.recover_paths(case,fixed_selected_IDs)` against the original canonical ordered trip/movement paths. The unchanged helper admits a fresh candidate only after unique IDs equal that exact fixed set, same fleet/case, physical replay and no failures. With passed copy contract, one call, timely admission and runtime unique recovery, the worker can therefore record `route_identity_method='source_guarded_unique_path_inference'`. This is explicitly inference from source guards, **not direct candidate replay or fallback-as-candidate comparison**. If any inference condition is absent, verification stays unknown and the cell cannot qualify. If `selected_source='direct_qp'`, the exposed selected candidate instead gets `direct_candidate_canonical_comparison` through independent replay/path checks. Parent approved this conditional policy after the bounded source proof; no helper mutation or alternative solve is introduced.

Per-cell numerical qualification does not establish a true fixed-route optimum error bar or permit route-preference certification; see `NUMERICAL_QUALIFICATION_CONTRACT.md`. This source remains subject to parent/peer static review and frozen-input admission. No runtime qualification is claimed.

Before the first pilot launch, parent selected a conservative compatibility-stop
policy: non-timeout failures in original_model/copy_contract before any native
call, and unexpected non-timeout helper-interface exceptions, latch fatal caller
status and stop later cells. They do not invalidate the old physical fallback,
authorize a helper edit or trigger a retry.
