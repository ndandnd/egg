## Smallest nonlinear master, with an explicit target

An EGG-local master can consume these coefficients with binary `x[r]`, the unchanged service, fleet, station-minute and terminal rows, and a fresh nonlinear economic objective. It needs no copy of the sibling pricer, DP or route builder. Its result is a finite retained-column selection. Even native optimal status establishes only optimality for this explicit finite coefficient model, subject to its numerical qualifications; the sibling linear pricing certificate cannot certify omitted columns for the new objective.

Define the economic aggregation first: `L[tau] = sum_(r,s,h) M[tau,s,h] e[s,h,r] x[r]`. The fixed matrix M states whether a tariff applies per station or to a common portfolio. Do not silently merge distinct physical station constraints. Any separately declared station adder `sigma[s,h]` contributes `sum sigma*e` outside the aggregate market function; freeze it explicitly, including zero if absent. Background `U` belongs to the economic objective and is not deducted from fleet charger power or plug capacity. For a prospectively specified `(a,b,U)` and the convention `sum(alpha*L + 0.5*beta*L^2)`, system-increment coefficients are `alpha=a+bU,beta=b`; endogenous uniform-price payment coefficients are `alpha=a+bU,beta=2b`. An externally posted quote has `beta=0`. These are different modeled targets, not interchangeable names for a realized market institution. Add `sum c[r] x[r]` once; never add the bank-generating linear electricity cost again.

Two honest target alignments are possible, and must not be mixed after seeing results:

1. **Conservative-grid target:** use `eg`, grid occupancy and the original grid terminal row. This retains the event-grid economic target. Report realized nonlinear value of the selected fleet separately. A grid-objective improvement is not automatically an improvement in delivered continuous cost.
2. **Frozen-realized-witness target:** use `ec` for the economic target, retaining original conservative grid occupancy and original grid terminal requirements, and also the declared realized aggregate terminal requirement used for physical admission. This optimizes delivered values of the particular deterministic mapped witnesses while retaining conservative physical rows. Revalidate the jointly selected fleet under the same stations, power map, reserve, horizon and target. It is neither joint continuous schedule optimization nor a continuous-cost pricing certificate. Dropping the grid rows or substituting an easier terminal condition would define another model.

For an operational nonlinear comparison, the second is the smaller honest delivered-target seam; the first can be a separate grid diagnostic. Both methods must protect the same previously admitted incumbent in the same target representation and pay extraction/master work. Report both load representations and the source quote used to generate the bank. A bank generated under one linear quote can miss valuable alternatives under nonlinear aggregation even if its retained-bank master is solved optimally. There is no guaranteed nonlinear dominance from having a larger search label alone.
