Only fixture.py and this note are new. No descriptor was generated, module imported, hash evaluated, test/compile executed, old artifact read or numerical call made while authoring. Caller must gate and bind the frozen source before invoking it, and pay descriptor creation, hashing, pandas construction and graph work inside prospective clocks. Importing fixture.py uses stdlib only and does not call its generator.

Public API:

- `make_descriptor(seed,n,quote)` accepts exactly61001–61004,12/24 and `flat`/`source_shape`. It returns a JSON-ready dictionary with string mapping keys, explicit complete adjacency, trips/duties, times/energy, registered labels/horizon, resources/quotes, schema and overlap witness. SHA jitter is computed only on a future actual call, using the exact frozen UTF-8 seed/wave rule; no global PRNG or size-dependent draw sequence.
- `make_fixture(boundary,pandas,descriptor)` returns `(problem,prices,plugs,duties,physics,descriptor)`, matching the old six-part call shape. It uses the caller's already-loaded registered boundary and pandas; prices/hour and problem/trip keys are converted to the source's integer domains without changing descriptor wire keys. A real synthetic DataFrame is supplied, never a dummy or private input.
- `physical_alias(descriptor)` returns canonical JSON excluding seed label, quote label and price values. It preserves physical times, service energy, transfers, duties and resource fields. Compare both12/24 variants per group before outcomes; join groups on any same-size match transitively, retain every assignment and collision, and never replace seeds. Fewer than four distinct declared group clusters makes the continuation screen inconclusive. This API returns an equality key, not a claim that different synthetic keys prove statistical independence.
- `assert_nested(small,large)` checks the same-seed/same-quote12/24 pair: unchanged trip prefix, duty prefix, all resource/quote/schema fields and induced adjacency. Larger variants retain existing depot/station boundary arcs. No resources scale with size. Caller should also compare physical aliases across quotes for each seed/size; quote contexts must not change physics.

Constants `FIXTURE_ID`, `SEEDS`, `SIZES`, `QUOTES`, `PHYSICS`, `EXPECTED_COSTS`, `DEPOT`, `STATIONS`, `BASES` and `ACTIVE` are available without generation. The selected design requires **no hand-built charging witness or guaranteed-feasible eligibility condition**. A0 is an actual paid flat-quote acquisition under each assigned group/size/restriction and may fail. An independently admitted A0 fleet can be the shared external target fallback. Missing A0 leaves C1 unavailable but F1 cold-eligible; no seeds, plugs, energy, terminal target or case count may be adjusted to rescue it. All16 sequences/48 states remain explicit. This constructor does not import an oracle, replay a plan, assert initial/terminal SOC feasibility, cache columns or certify native-model equivalence.
