# Independent target-proof adapter API

All functions are source-only/unexecuted at handoff. No I/O, solver, search or owner is implemented here. Target identity is OLD_ID+'::exact-consumption-v1'; original identity is never relabelled as the target.

1. `validate_semantics(selected_decimal_document, original_binary_descriptor, target_record, original_reconstruct, target_reconstruct, admit_inputs)` independently derives all exact energies and unchanged-field mappings, then calls each semantic callback once. The complete target six-tuple must equal the original structural ledger with only explicitly verified per-leg y-energy coefficients, service-energy RHS values and independently refreshed minimum-fleet RHS/evidence. It returns a VALIDATED_TARGET_SEMANTICS record with target case and cached ledger.
2. Retain `validation_seal=seal(validated)` SEPARATELY immediately after validation. Never reseal edits. `cached_reconstruct(validated,validation_seal)` checks the original validation seal and exact target-case content before returning a private copy of the cached ledger; use it for both fixed-route builders and final tree preparation, avoiding repeated target reconstruction.
3. `verify_retained_tree(validated,validation_seal,old303,refinement,immutable_treechecker,limits,admit_proposals)` grafts the fixed303+72 partition, retains every original152 frontier identity and strips old claimed_lower/claimed_contradiction/status fields from selected leaf proposals. Historical claimed lowers may select an old/new proposal heuristically but prove nothing. One fresh complete375-node check uses target rows and a fresh one-bus obstruction/three-plus floor. Any invalid or nonpositive old Farkas contradiction returns UNRESOLVED; no retry, replacement topology or old-bound fallback. Explicit caller limits must set nodes=375/depth=375 and prospectively fund the other checker limits.
4. `check_mixture(left,right,lambda_left,lambda_right,target_identity,admit_point,claimed_upper=None,*,weight_record,admit_weights)` requires two NEW ADMITTED_TARGET_PRIMAL objects, fresh strict replays, matching replay/load/ops/objective and original binary supply coefficients. Both frozen routes use two buses and fee200. Required weight callback binds the actual historical fixed-weight record; arbitrary newly selected weights are not admitted. It computes the new mean/objective and never reads an old objective/KKT claim. Optional claimed_upper must equal the new computation.
5. `conclude(bound,mixture)` requires the same new target identity and a target lower consistent with an admitted physical upper. Exact lower>new hull upper yields POSITIVE_TARGET_GAP_CERTIFIED; otherwise TARGET_GAP_UNRESOLVED. No exact optimum or CH lower is inferred.
6. `literal_qualification()` contains only tiny pure parser/proposal/identity/new-objective/weight controls with explicitly MOCK admissions. It does not replace the separately authored full transformation fixtures or target semantic comparison.

## Authority boundaries

The validator accepts only the authorized projection: top-level native_cases/source_data; exactly one selected15 variant with selected_depot_id,case_identity,trips,movement_modes,movement_provenance; and shared deadhead_stop_order_source/deadhead_arcs_directed_row_major only. This shape is checked BEFORE recursive seals or admission callbacks. Worker must project and discard full rich data first, reading only selected_depot_id on unselected variants. It must not recursively seal unrelated cases.

Every admit callback must bind the actual newly constructed/admitted object AND its separately retained immutable content/manifest seal. Identity alone or a self-issued True/PASS flag is insufficient. `admit_inputs` additionally binds the same original rich/descriptor/canonical closure buffers; `admit_proposals` binds the fixed old tree/refinement artifact paths; `admit_point` binds the actual newly screened physical object; `admit_weights` binds the historical fixed-weight projection. No function follows data-controlled paths or authenticates buffers merely by checking a supplied revision string.

The old original and new target semantic sources must be separately pinned. The target semantic callback's implementation is not trusted simply because it claims to copy old code: the validator checks its entire output. Nonenergy input representation remains original binary numeric fields; target energy fields are canonical nonnegative integer/fraction strings, never float round-trips. The source decimal law and stored-binary supply coefficients remain distinct.

The module proves only the new finite target certificate obligations. A separate analytical canonicalization/inclusion theorem is required to extend that target to all finite modeled paired-arc walks; empirical route realization remains outside scope.
