# Independent checker controls: prospective, unexecuted

API: independent.independently_check(projected,claimed). The module imports only Fraction and never calls the extractor or producer. It builds its own typed-ID index and both exact matrices. Source order is authoritative; the triangle(i,j,k) slack is M[i,k]+M[k,j]−M[i,j]. All repeated-index triples count. Negative entries and nonzero diagonals are distinct failure counts; triangle witnesses are first20 separately per metric.

For a complete well-formed input, status and all scientific summary counters, exact minima and typed witness records are compared. PASS requires a passing metric gate and matching summary. A genuine metric FAIL with matching summary returns FAIL with summary_matches=true. Forged summaries return FAIL; malformed/oversized inputs and arithmetic uncertainty return UNKNOWN, never partial PASS. Diagnostic schema-error taxonomy is independently authored and is not required identical. No fixed-path/source authentication is supplied by this pure function: the future worker must bind the actual source projection separately.

Suggested literal controls, to be executed only in a future authorized qualification:

1. Three locations in declared order A,B,C; symmetric distance0/1/2 along a line, time twice distance. All9 arcs,27 triangle checks per metric, minslack0, no failures. Exact fractional scaling gives the same conclusion. Shuffle arc-list order without changing declared locations: summary/witness order unchanged.
2. Change only A→C distance from2 to3. Distance triangle at(i=A,j=C,k=B) has slack−1; time must still pass. No support/routing conclusion follows from that failure.
3. Independent time-only violation; both-metric violations; more than20 violations to verify full counts but capped deterministic witness lists.
4. Negative arc and nonzero diagonal: FAIL with all27 triangles still checked; retain distinct negative/diagonal/triangle counters rather than short-circuiting.
5. Missing/duplicate arc, foreign endpoint, missing field, extra arc field, empty/duplicate/boolean/float ID or int1/string"1" alias: UNKNOWN with no accepted complete metric certificate.
6. Boolean/float quantity, malformed rational, zero denominator, nonfinite string, missing/wrong units or missing/oversized source_bytes: UNKNOWN. Exact integer/string fractions are allowed, with input rational bits at most4096.
7. More than256 locations or a coefficient exceeding the input bit ceiling: UNKNOWN. No capped prefix of a matrix may return PASS. Arithmetic ceiling32768 must also fail closed.
8. Corrupt each claimed count, either minimum slack, witness index/source ID/slack, witness order or status: reject summary agreement. Boolean witness indices must not compare equal to integer indices. Different harmless diagnostic taxonomy is not itself a scientific discrepancy.

This gate establishes only the specified finite OD metric property. Metric failure blocks that sufficient canonicalization argument; it is neither a proof that support returns nor a replacement for the separate terminal-access/common-policy conditions.
