# Minimal incremental physical-certificate interface

Source-only design/implementation after reading PHYSICAL_TIGHTENING_DECISION.md, the new extractor contract and narrow immutable checker APIs. No actual old packets, descriptors, artifacts, imports, tests, hashes, execution or dispatch were consumed. Old sources remain unchanged.

## Trust boundary and API

`checker.verify_refinements(context,base,packet,checker,admit_base,limits=None)` requires a context freshly reconstructed from the authenticated original case with quadratic objective and fleet_count=2. The callback must authenticate this exact extractor-produced base object against the prospectively pinned cached input buffers. A dictionary merely claiming SOURCE_BOUND_BASE_ADMITTED is insufficient. The extractor adopts the old numerical audit; this wrapper rechecks only its transparent branch structure/frontier identities and inherited prefixes, not old multipliers or bounds.

The packet has `refinements`, mapping EVERY adopted frontier leaf ID to a local flat root/nodes tree, and optional `proofs`, containing NEW certificate vectors by reference. A retained finite leaf is a singleton `{kind:'base_bound',base_leaf_id:...}`. Old infeasible leaves remain singleton base_infeasible (base_bound is also accepted only when the admitted original status is infeasible). No base leaf can be omitted, substituted or assigned a different prefix. Old roots are adopted partition evidence; the new-node denominator sums local node counts minus one, counting newly created descendants and not charging old roots as new work.

Final interface also requires `base_seal=seal_base(base)`, made ONCE immediately after authenticated extraction and held separately. This recursive immutable exact representation is compared before and after verification; it is not a hash or source authenticator. Identity alone is insufficient because the same mutable object could have its lower, floor or prefix altered. The consumer must bind the seal to the authenticated projection and manifest, not reseal an edited object at final audit. A fresh semantic minimum_fleet_proof>=2 is independently required in addition to the admitted base obstruction.

`verify_local(context,root_decisions,tree,checker,base_leaf,limits=None,proofs=None)` transparently walks a full binary subtree. Local branch paths append to the adopted inherited decisions. Branching again on an inherited/fixed movement, shared/missing/cyclic/unreachable nodes or omitted children is rejected. NEW bound/infeasible leaves alone invoke unchanged exact checker.verify_node with the entire inherited-plus-local path. This avoids a generic opaque trusted-leaf mode or a new solver/controller. The immutable checker independently verifies the new tangent/dual/box/Farkas algebra.

An adopted finite bound is valid on every descendant and can explicitly terminate any new fringe leaf. Every newly checked finite lower is combined with it by maximum. The minimum over a complete local fringe bounds its original base region. A new infeasible leaf needs a strictly checked contradiction; native status is never input authority. An invalid/open/timed-out local tree is explicitly recorded as rejected and falls back to its adopted old region bound, never to an improved claim. The final status distinguishes a valid refinement from valid base coverage with rejected refinements.

Complete adopted base partition coverage plus all local outcomes gives the final exactly-two lower. Combining it with the adopted typed physical three-plus floor and minimum-fleet obstruction gives global D. A lower contradicting the protected admitted physical upper, a weakened adopted global lower, or an all-infeasible physical partition is rejected. The result is never a CH lower. Fixed epsilon and upper-minus-epsilon target are checked exactly.

## Required prospective qualification

The thin consumer must bind the base admission callback, context/case identity, old floor/upper/source pins, exact frontier denominator and prefix equality. Literal controls should reject missing/foreign/duplicate base leaves, changed inherited decisions, foreign base-bound IDs, missing binary children, repeated inherited branching, changed oldlower/floor prior to callback authorization, bad new certificates, and a native-only infeasible leaf. A budget-stopped subtree should retain explicit base_bound fringe leaves; an invalid subtree should preserve the old bound with an explicit diagnostic. No callback should authorize a mutated copy simply because it retains the same status string.

Limits are finite for local/total new nodes, depth, elapsed audit and per-node exact checker time. Immutable checker arithmetic limits remain in force; resource exhaustion cannot produce a stronger bound. The worker/owner must separately fund total model/search/extraction/final-audit/publication time and count only new native calls/nodes. This source helper does not claim resource qualification or authorize a run. Independent source review is needed before freeze.

The new qualification.run(wrapper,extractor=None) uses synthetic contexts and a deliberately mock exact-node checker only to exercise source-admission/coverage/prefix forwarding/fallback. It does NOT repeat or claim numerical exact-algebra qualification. The prospective controls include same-object mutation after sealing, foreign/denied authority, missing seal/base IDs, weaker new bounds, missing/repeated branches, wrong inherited proof path, native OPTIMAL-only evidence and open fringe. Outcomes remain unknown until the parent freezes and executes the new package.
