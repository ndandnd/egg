## What CC BY4.0 would permit, if confirmed for these files

The [official Creative Commons deed](https://creativecommons.org/licenses/by/4.0/) permits redistribution and adaptation, including commercially, provided attribution, a licence link and change notices are supplied and no prohibited additional restrictions are imposed. Its notices expressly do not warrant that every right needed is licensed. The [legal code](https://creativecommons.org/licenses/by/4.0/legalcode.en) governs; the deed is only a summary. These are conditional licence implications, not a finding that the Hildenbrand file is covered.

For a dataset file actually covered by CC BY4.0, an appropriate notice would identify the four named creators, full dataset title, version1 DOI, repository licence and any supplied copyright/disclaimer notices. It should separately describe EGG's selection, depot modifications, retained offsets, synthetic energy/economic coefficients and derived graph/certificate construction, with no implication of the original authors' endorsement. Preserve any earlier modification notices and file-specific attribution if supplied.
