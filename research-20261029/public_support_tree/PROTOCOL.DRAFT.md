# DRAFT: bounded quadratic physical-bound tree producer

Source-only proposal, not launch authority. No workload, owner, command, source revision, target or funding is frozen here. Parent review and independent producer/checker qualification precede any new search. No old root gzip is reopened or recomputed for a seed.

`producer.produce` receives cached source modules, the original public case descriptor, a source-bound admitted feasible-mixture target authority and a separately admitted physical three-plus-bus affine floor. Target metadata paths are never followed. The global higher-fleet floor must exceed the target, and the exact semantic minimum-fleet proof must exclude one bus. Only then search the exact-two-bus subproblem. This restriction bounds physical D; it is not a restriction of CH.

The prescribed initial bound is the exact fleet fee from an explicit zero supply tangent and the two-bus equality. It is checked once and labeled elementary, never a missing-native-evidence fallback success. A new conditional `sum_pullouts=2` root QP is a stronger physical relaxation than the existing unrestricted-hull/minimum-fleet root. No old numerical root packet is an input.

Use one continuous per-leg energy-flow model, one process and one native thread. Reuse that model and its solver state. Attach the full original quadratic objective; add exact-named branch equalities only on original movement binaries. At each node take one fully funded conditional QP proposal. Its native bound/status is not proof input: multipliers and an explicit tangent are checked against independently reconstructed exact source rows and finite boxes. Retain the stronger of the inherited exact bound and the newly checked bound.

Best-bound priority is the smallest exact leaf lower bound; ties prefer deeper nodes, then creation order. Choose the most fractional unfixed original movement from the numerical primal, with source order breaking ties. The1e-7 branching threshold is heuristic only. If no such fractional movement exists, choose the first unfixed original movement. Always create both0/1 children together. Each inherits its parent's valid certificate without changing its proof vector.

For native INFEASIBLE/INF_OR_UNBD, attempt an exact check of the proposed Farkas vector. If no positive exact contradiction is available, at most one prescribed zero-objective LP conversion at that same node is allowed, with its own separately logged/funded call and cap. It is not a quadratic objective retry or an automatic closure extension. If that LP still gives no exact contradiction, retain the inherited bound and an explicit open/failure state. Native infeasibility alone never prunes a node.

The caller must freeze every limit explicitly: node count, total native calls including feasibility LPs, total producer CPU/wall allowance, per-QP allowance, per-feasibility-LP allowance, per-exact-check allowance and CPU/wall closure reserves. A new native call is admitted only with its full call/check/publication reserve. Process CPU is measured inside the single-process producer, with all outer admission/audit costs separately included in the worker/package meter. No cap increase, method alternative, strong-branch probing, terminal adjustment, primal repair or native retry is automatic. Any native error, exact-check failure or limiting event is retained.

Store exact certificate vectors once by proof ID. Tree leaves refer to those IDs; inherited proofs are not repeatedly serialized. Keep all branch nodes and all search-open leaf states. Do not dump large raw solver iteration streams or full native primal vectors. Native call summaries and the selected branching guide value are sufficient heuristic telemetry. `materialize_tree` expands references only in memory for one final independent `checker.verify_tree` call in the future thin worker.

A frontier can have complete valid bound coverage while search remains open because some lower bounds do not exceed the target. Report these separately. Stop proposing success only when every frontier leaf has a verified contradiction or a verified lower strictly above the admitted target. The producer labels this TARGET_COVERAGE_PROPOSED, not an independently certified result. Final tree coverage, the physical three-plus floor and the admitted hull upper must establish the exact strict inequality before a public positive-gap claim. Budget exhaustion publishes all valid weaker bounds and open states and does not establish support or an exact integer optimum.

The worst case remains exponential. This is a classical full-graph physical-bound search, not a learning method, a duty-bank relaxation or a claim of scalability. New commands, fixed input paths/revisions, source closure, backend identity, process funding and external resource accounting remain entirely pending parent freeze.
