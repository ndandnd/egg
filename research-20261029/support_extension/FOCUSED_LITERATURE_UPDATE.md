# Focused aggregation comparison update — 29 October

One targeted search checked whether recent exact aggregation already couples
V2G with grid decisions. [Arvis et al., v2](https://arxiv.org/html/2511.11191v2),
Sections II-A/B and IV, does so for prescribed user profiles. The inspected
equations fix availability and driving consumption; they do not supply the
assignment-dependent vehicle-cost frontier claimed here. This is a limited
comparison, not a novelty guarantee. The draft now cites this overlap explicitly.

[University of Twente's publication record](https://research.utwente.nl/en/publications/exact-characterization-of-aggregate-flexibility-via-generalized-p-2/)
confirms Mukhi--Loho--Abate in IEEE TSG17(3),2131--2142,2026,
DOI10.1109/TSG.2026.3659513. Its accepted-PDF link returned403, so no accepted-text
inspection is claimed. ArXiv still identifies v2,17June2025 as its latest version.
Bibliographic metadata is updated while the technical comparison remains
explicitly bound to that inspected preprint; no assumption that versions are
identical is needed. No broader literature expansion or numerical work occurred.
