# Feasibility of one new fixed-price global hull lower

Bounded source/compact-record assessment only. Read the closed public_hull_lower/public_hull_repaired RESULTS and repaired protocol, plus the narrow admission, linear producer and immutable tree-checker APIs. No prices, loads, proof products, raw inputs, native model, hashes, replay or numerical calculation were consumed. No new code, control or dispatch is proposed here.

**Recommendation: do not authorize the proposed solve merely because D is now tight.** For the ORIGINAL binary-consumption model, the same admitted mixture-gradient/all-fleet linear bound question has already been attempted. The cause-based repaired package closed validly at255 nodes/131 new native calls with an open fringe, at223.62 displayed CPU seconds. Its valid hull lower427.968400 was weaker than the retained434.17 lower. This is neither proof that the price is intrinsically poor nor evidence that another budget would succeed. Raising the cap on the same source/method/price would be a continuation of that unresolved question, not a new scientific direction. A materially new price-specific fleet exclusion or independently justified proof strategy could justify a separately frozen attempt; it has not yet been established by this assessment.

## What the bound would actually prove

For the admitted mean load u_bar, let p=grad F(u_bar) and k=F(u_bar)−p.u_bar. Any exact ALL-FLEET private-score lower ell<=V(p)=min_physical[c+p.u] gives

    CH >= k+ell.

This follows from the supporting tangent on every physical plan and hence every complete-plan mixture. It is independent of the already tight physical D enclosure. The branched quadratic D lower cannot substitute for ell or be called a CH lower. Old quadratic multipliers are not valid new-price linear certificates by assertion. Even exact V(p) need not make k+V(p) equal the admitted mixture upper: a two-plan segment optimum does not establish global hull stationarity. Thus an epsilon1/10000 target around that upper may be unattainable at this price, regardless of compute.

The immediate useful goal would be strict improvement over the best existing model-specific CH lower, with the requested accuracy as a separate outcome, not a success gate that discards a weaker but valid result. Any exact positive improvement must be retained alongside its cost. A valid but weaker lower leaves the old best bound unchanged.

## The only promising small gate before considering another attempt

At nonnegative p, the immutable checker supports a typed price-specific three-plus floor:

    V_ge3(p) >= 3*f + min_t p_t * mandatory_service_energy/efficiency,

under its explicit nonnegative movement/cost/full-refill premises. For a two-bus proof the record must bind the exact price vector, proof_kind='linear_min_price_service_floor', scope='response_ge_3', and have separate source-bound authority; the checker recomputes its value. Zero/one-bus exclusion must ALSO remain valid. If this floor reaches a prospectively selected linear target, larger fleets need not be branched to that target. Otherwise either all fleets must stay in the proof or the eventual global lower must be capped by the valid higher-fleet floor; simply claiming all-fleet coverage from a two-bus tree is invalid.

The nominal nonlinear three-plus exclusion cannot be imported under its old type. Nonnegative mixture loads imply p>=the original positive linear supply coefficient, which makes a useful floor plausible, but its comparison with the requested linear target must be performed exactly under a new authorized metadata gate. No such comparison is asserted here. This objective-specific exclusion could change the search domain materially, unlike an arbitrary larger node budget. The existing all-fleet producer would require a narrow reviewed two-bus/floor adaptation; the checker already has the necessary acceptance interface. Fresh linear node proposals would still be needed. No old quadratic375-node success predicts linear-price leaf quality.

## Resource and model decision

One thread/<=5GiB and1800CPU/2400wall are mechanically compatible with the existing LP/branch/check architecture, whose previous observed memory was below that ceiling. They do not establish that a useful lower is reachable. Branch count, exact residual strength and fixed-price duality gap are unbounded by those receipts; extrapolating255 nodes to a guaranteed result is unjustified. A prospective attempt must fund NEW admission/transfer, full next LP allowances, exact proposal checks, publication and a protected final complete all-fleet audit/kill-reap reserve. No package retry, old literal suite, physical replay or old tree audit is scientifically needed; no closed directory should be resumed.

Specify the consumption model first. The434.17 root lower and the repaired metadata belong to the ORIGINAL binary model. The NEW exact-additive target has distinct rows, admitted loads and mixture-gradient fractions. It cannot inherit those lower certificates/price metadata merely because six-decimal displays match. A new exact-target fixed-price question could be distinct, but would need its own target-valid metadata and semantic cache transfer; no such numerical lower is implied here.

Decision boundary: if a separately authorized cheap exact price-specific fleet-floor gate establishes a genuinely smaller complete proof domain and the scientific goal is explicitly a better CH interval, one bounded NEW proof attempt could be defensible, with unresolved/weak output accepted honestly. Without that change, recommend no solve: the public sign and physical precision are already resolved, the same-price all-fleet method already produced a weaker bound, and a tighter CH number is unlikely by itself to change the paper's novelty or practical-value assessment. This note is feasibility advice, not authority for that gate or any native call.
