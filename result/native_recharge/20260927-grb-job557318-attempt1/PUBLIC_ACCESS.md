# Public evidence and original archive

This public directory contains 92 unchanged original input, event, numerical
result and process-accounting files. Fifteen original worker stdout files are
not distributed because they contain licensing infrastructure identifiers.
`PUBLIC_MANIFEST.json` lists both public files and the original sizes/hashes of
each omitted file. `MANIFEST.json` is the unchanged complete 107-file manifest
created on Unicorn after the job ended. It is intentionally not a manifest of
only the visible public subset. No event, native variable, objective, witness,
exception or target has been edited or omitted.

The complete 107-file original archive was transferred with hash verification,
preserved locally and independently audited. The independent audit script takes
an external `--attempt` path. Full original-manifest verification needs that
complete archive and correctly fails on this partial public copy. The public
review reports the actual full audit; a reader's public-subset integrity check
is a narrower operation and must not be described as that full audit.

The derived review has a separate manifest. `SLURM_RECEIPT.json` records the
non-sensitive scheduler result; original stdout/stderr/submission records remain
in the local evidence archive. The source was published before dispatch and no
job was retried. Timing on this tiny qualification is not a backend comparison.
