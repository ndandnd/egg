The two-window engine was separately tested on small artificial inputs only. The first invocation crashed in CVXPY's default Eigen canonicalization before a fixture observation (SIGBUS, 0.57 CPU/1.30 elapsed seconds). Switching to SciPy exposed mismatched sparse matrix shapes in dimension broadcasting (0.57/0.70). A compiler-only localization took about 0.61 elapsed seconds with CPU unmeasured. Explicit row tiling fixed the shape error. The third suite invocation found a Clarabel cached-solution API mismatch during result extraction (0.60/0.71). Handling the installed cached solution fixed the error. The final suite passed all three tests (0.69/0.84). These figures include imports; tool-reported elapsed seconds and displayed external timer values are approximate. There were no study-day runs in this work.
